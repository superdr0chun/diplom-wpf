# Система компьютерного тестирования — Десктопное приложение

WPF-клиент для системы тестирования. Подключается к Django-серверу через REST API. Используется студентами для прохождения тестов.

## Возможности

- Регистрация и авторизация через REST API сервера (JWT-токены)
- Список доступных тестов с поиском по названию и дисциплине
- Прохождение тестов с поддержкой трёх типов вопросов:
  - один правильный ответ
  - несколько правильных ответов
  - открытый вопрос
- Таймер с цветовой индикацией оставшегося времени
- Автоматическое завершение теста при истечении времени
- Защита от случайного закрытия окна
- Античит: фиксация переключения на другие окна
- Просмотр своих результатов с детальным разбором ошибок
- Оффлайн-режим: кэширование тестов и автоматическая отправка результатов при появлении связи
- Тёмная и светлая тема (запоминается между запусками)

## Установка и запуск

### Шаг 1. Запустите backend

Перед запуском клиента должен быть запущен Django-сервер (см. репозиторий [diplom-django](https://github.com/superdr0chun/diplom-django)).

### Шаг 2. Клонирование

```bash
git clone https://github.com/superdr0chun/diplom-wpf.git
cd diplom-wpf
```

### Шаг 3. Открытие проекта

Откройте `diplomWPF.sln` в Visual Studio. NuGet-пакеты восстановятся автоматически.

### Шаг 4. Запуск

Нажмите **F5** или **Debug → Start Debugging**.

По умолчанию приложение подключается к серверу `http://127.0.0.1:8000/api`. Адрес можно изменить в `Services/AuthService.cs` (`BaseUrl`).

## Структура проекта

```
DjangoWPFClient/
├── Models/
│   └── UserSession.cs          — данные текущего пользователя
├── Services/
│   ├── AuthService.cs          — общение с REST API
│   ├── ThemeManager.cs         — управление темой
│   └── OfflineCache.cs         — кэш тестов и очередь результатов
├── Themes/
│   ├── Light.xaml              — светлая тема
│   └── Dark.xaml               — тёмная тема
├── Views/
│   ├── LoginWindow.xaml        — окно входа
│   ├── RegisterWindow.xaml     — окно регистрации
│   ├── TestListWindow.xaml     — список тестов
│   ├── TestWindow.xaml         — окно прохождения
│   ├── ResultWindow.xaml       — результат после прохождения
│   ├── MyResultsWindow.xaml    — история результатов
│   └── ResultDetailWindow.xaml — разбор ответов
├── App.xaml                    — стили и ресурсы
└── MainWindow.xaml             — стартовое окно
```

## Возможные проблемы

**"Не удалось подключиться к серверу"** — проверьте что Django-сервер запущен на `http://127.0.0.1:8000`.

**В оффлайн-режиме нет тестов** — нужно один раз войти онлайн, чтобы тесты сохранились в кэш.
